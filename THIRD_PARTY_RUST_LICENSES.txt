SCOPE AND PROVENANCE

This bundle covers every external registry package in the committed Cargo.lock,
including Windows, Linux, other target-specific, build and development
packages. Inclusion here does not mean that a package is linked into every
binary. The application license and upstream/HeadsetControl attribution are
provided separately in LICENSE and THIRD_PARTY_NOTICES.md.

Package names, versions, registry source identifiers and archive checksums are
copied from Cargo.lock. Declared license expressions and repository URLs are
copied from each exact package's Cargo.toml. Registry file bodies are read
directly from the original .crate archives after verifying each complete
archive against its SHA-256 checksum in Cargo.lock. Source revisions come
from the packaged .cargo_vcs_info.json, when present.

Packages whose archives contain no notice files require explicit supplemental
metadata in scripts/rust-notices-upstream.json. Each supplemental original file
is pinned to the source revision recorded in that exact crate archive and
verified against its Git blob identifier. Pinned URLs and blob identifiers
are recorded below. AUTHORS files are included because some packages carry
their copyright attribution or license grant in those files.

Part I maps every package and source file to its SHA-256 text identifier.
Part II contains the complete original file bodies. Identical bodies are
included once and explicitly referenced by every package that supplies them.
The byte counts and SHA-256 identifiers describe the original UTF-8 file
bytes, excluding the surrounding BEGIN/END markers and separator linefeeds.
No license text was synthesized from an SPDX identifier or substituted with
a generic license template. Preserve this bundle with binary distributions.
After Cargo.lock changes, run cargo fetch --locked and then
python scripts/rust-notices.py --write. CI uses --check without modifying files.
